    구글 시트 실시간 공유

    로컬 저장

    아래에 웹앱 URL을 넣으면 두 사람 폰이 같은 구글 시트를 보고, 기록이 바뀔 때마다 자동으로 주고받아요. URL이 없어도 이 폰에 안전하게 저장됩니다.

    이 폰에만 저장 중이에요.

    2분 따라하기

    한 번만 하면 돼요
    1. 구글 시트 만들기시트.new 또는 드라이브에서 새 스프레드시트를 만들고 이름을 ‘러브장 데이터’로 정해요.
    2. 확장 프로그램 → Apps Script시트 위쪽 메뉴에서 확장 프로그램 → Apps Script를 눌러요.
    3. 아래 코드 붙여넣기편집기의 기존 내용을 모두 지우고, 아래 Code.gs 코드를 통째로 붙여넣은 뒤 저장(Ctrl+S)해요.
    4. 웹앱으로 배포배포 → 새 배포 → 유형 ‘웹 앱’, 실행 계정 ‘나’, 액세스 권한 ‘모든 사용자’로 배포하고 권한을 허용해요.
    5. URL 복사 → 위에 붙여넣기나온 웹 앱 URL을 복사해 위 칸에 넣고 저장하면 끝! 와이프 폰에도 같은 URL을 넣으면 둘이 같은 장부를 봐요.

    코드를 고치면 배포 → 배포 관리 → 수정 → 새 버전으로 다시 배포해야 반영돼요.

    Code.gs

    아래 코드를 그대로 붙여넣으면 시트 안에 데이터를 저장하고, 두 기기가 같은 JSON을 주고받아요.

    백업 · 복원

    가져온 파일은 같은 항목을 최신 내용으로 합쳐요. 내보낸 파일은 다운로드 폴더에 저장돼요.

    저장된 기록

    이 폰의 저장 공간(localStorage)과, 연결했다면 구글 시트에 함께 저장돼요.
