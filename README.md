# 💕 선빈♡병철 러브장

부부가 함께 쓰는 **가계부 · 대출 · 카드 관리 PWA**입니다.
바닐라 HTML/CSS/JS로 만들었고, 구글 시트(Apps Script 웹앱)와 연결하면 두 사람 폰이 같은 장부를 실시간으로 봅니다.

## 이런 걸 할 수 있어요

- **홈(요약)** — 월 선택, 부부 합산 수입/지출/순수지, 병철·선빈·공동 비중, 전체 대출 상환율, 이번 달 카드값
- **수입·지출** — 명의·구분·날짜·금액(빠른 버튼)·분류(직접 추가)·메모로 기록, 필터·수정·삭제
- **대출** — 은행별 원금/잔액/금리/상환일 관리, 카드마다 개별 상환율 바, `상환 기록`으로 잔액 차감 + 이력 저장
- **카드** — 병철·선빈 카드값과 결제일, 납부 완료 체크, 결제 전/완료 구분 합계
- **공유·관리** — 구글 시트 웹앱 URL 연결(불러오기/보내기/자동 전송), Code.gs 코드 복사, 2분 따라하기, JSON/CSV 백업·복원, 예시 데이터, 전체 지우기

## 폴더 구성

```
index.html              화면 (탭 5개 + 모달)
styles.css              디자인 (모바일 우선, 데스크톱 2단)
app.js                  모든 기능 (데이터·계산·동기화·백업)
manifest.json           PWA 설정 (이름: 선빈♡병철 러브장)
sw.js                   서비스 워커 (앱 껍데기 오프라인 캐시)
icon-192.png            아이콘
icon-512.png
icon-maskable-512.png   안드로이드 마스커블 아이콘
```

## 폰에 설치하기

1. 저장소를 GitHub Pages로 올립니다. (Settings → Pages → Branch: `main` / root)
2. 폰 브라우저에서 `https://<아이디>.github.io/<저장소>/` 를 엽니다.
3. Chrome이면 **홈 화면에 추가**, 아이폰 Safari면 **공유 → 홈 화면에 추가**.
4. 이후에는 앱처럼 전체 화면으로 열리고, 비행기 모드에서도 화면이 뜹니다.

## 구글 시트 연결 (한 번만, 약 2분)

1. 새 구글 스프레드시트를 만들고 이름을 `러브장 데이터`로 정합니다.
2. **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기 내용을 모두 지우고, 앱의 **공유·관리 → Code.gs → 복사**한 코드를 붙여넣고 저장(Ctrl+S).
4. **배포 → 새 배포 → 유형 '웹 앱'**, 실행 계정 `나`, 액세스 권한 **`모든 사용자`** 로 배포하고 권한을 허용합니다.
5. 나온 **웹 앱 URL**(`.../exec`)을 앱의 **공유·관리 → Apps Script 웹앱 URL**에 붙여넣고 **저장**. 와이프 폰에도 같은 URL을 넣으면 끝.

> 코드를 고치면 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
> 액세스 권한이 '나만'이면 다른 폰에서 읽을 수 없습니다.

## 데이터는 어떻게 저장되나요

- 기본은 이 폰의 `localStorage`에 100% 저장됩니다. URL이 없어도 모든 기능이 동작합니다.
- URL을 연결하면 기록이 바뀔 때마다(1.8초 뒤) 자동으로 시트에 보내고, 앱을 다시 열거나 다른 탭에서 돌아올 때 시트에서 받아옵니다.
- 두 폰이 동시에 고쳐도 잃지 않도록 **항목별로 합칩니다.** 삭제는 표시를 남겨( tombstone ) 다른 폰에도 삭제가 전달되고, 60일 뒤 자동 정리됩니다.
- 브라우저 보안(CORS) 때문에 일반 요청이 막히는 환경에서는 **JSONP 읽기**와 **숨은 폼 전송**으로 자동 전환해 같은 방식으로 주고받습니다.
- 시트에는 `LOVE_DB`라는 숨은 시트의 A열에 JSON이 청크로 저장됩니다. 직접 읽거나 백업용으로 쓰기 좋습니다.

## 백업

- **JSON 내보내기** — 모든 기록을 파일로 저장 (복원은 `JSON 가져오기`, 같은 항목은 최신 것으로 합쳐짐)
- **CSV 내보내기** — 수입·지출 내역을 엑셀에서 열 수 있게 저장
